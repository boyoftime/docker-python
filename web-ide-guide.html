Deploying a Web-Based Python IDE (VS Code)

Run interactive Python scripts with inputs directly in your browser.

What is this?

The screenshot you shared is from PythonAnywhere. To replicate that exact experience on your VPS, we will install Code-Server (VS Code).

This gives you a full professional code editor in your browser. Unlike standard Docker containers, this allows you to open a Terminal and run scripts interactively, meaning input() will work perfectly.

Step 1: Create Directories

We need a place to store your code settings and your Python scripts.

mkdir -p /root/docker-deployment/code-server
mkdir -p /root/docker-deployment/code-server/workspace
cd /root/docker-deployment/code-server

Step 2: Docker Compose

Create the configuration file.

nano docker-compose.yml

Paste the following:

services:
  code-server:
    image: lscr.io/linuxserver/code-server:latest
    container_name: code-server
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Etc/UTC
      - PASSWORD=password  # CHANGE THIS PASSWORD!
      - SUDO_PASSWORD=password # CHANGE THIS PASSWORD!
    volumes:
      - ./config:/config
      # This folder will hold your Python scripts
      - ./workspace:/config/workspace
    ports:
      - 8443:8443
    restart: unless-stopped
    networks:
      - nginx-proxy

networks:
  nginx-proxy:
    external: true

Start the server:

docker compose up -d

Step 3: Secure with SSL

Now, expose it to the web so you can access it.

  1. DNS: Point `code.yourdomain.com` to your server IP.
  2. Nginx Proxy Manager:
    • Domain: `code.yourdomain.com`
    • Forward Hostname: `code-server`
    • Forward Port: `8443`
    • Websockets Support: ENABLED (Critical for the terminal to work)
    • SSL: Request Certificate & Force SSL.

Step 4: How to Run Scripts with Inputs

1. Open your browser to https://code.yourdomain.com.

2. Log in with the password you set in the Docker file.

3. In the file explorer on the left, right-click and create a new file named bot.py.

4. Paste your Python code (the one with input()).

5. To Run It:

  • Click the "Hamburger Menu" (Three lines) at the top left.
  • Go to Terminal -> New Terminal.
  • In the terminal at the bottom, type: python3 bot.py

Success! You will now see the prompt asking for input, and you can type directly into the browser window, exactly like PythonAnywhere.

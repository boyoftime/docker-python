What is WeasyPrint?

WeasyPrint converts HTML/CSS templates into PDF files. It's used to generate downloadable PDFs — such as payment link pages with QR codes — directly from your Flask app.

How it Works

  1. You write an HTML template with CSS (like a web page)
  2. WeasyPrint renders it as a PDF — no browser needed
  3. Images (QR codes, logos) are embedded as base64 data URIs since WeasyPrint doesn't have access to your web server

Why It Needs System Libraries

WeasyPrint is NOT a pure Python package. It depends on native C libraries for rendering:

  • libpango — text layout and font rendering
  • libcairo — 2D graphics and PDF drawing
  • libgdk-pixbuf — image loading (PNG, JPEG, etc.)
  • libgobject — object system used by all the above

Important: These must be installed at the OS level — pip install weasyprint alone is not enough.

Setup for Docker (Production)

In Docker, you install the system libraries directly in your Dockerfile. This is the simplest setup.

Step 1: Update Your Dockerfile

Add the system libraries to your existing RUN apt-get line:

RUN apt-get update && apt-get install -y curl libpango-1.0-0 libpangocairo-1.0-0 libgdk-pixbuf-2.0-0 libffi-dev libcairo2 && rm -rf /var/lib/apt/lists/*

Debian Trixie (Python 3.12-slim) Warning: The package is libgdk-pixbuf-2.0-0 (with hyphens), NOT libgdk-pixbuf2.0-0 (the old name). If you get "Package has no installation candidate", check the hyphens.

Step 2: Update requirements.txt

Add WeasyPrint to your Python dependencies:

weasyprint

Step 3: Rebuild the Container

docker compose down && docker compose up --build -d

That's it for Docker. The container has everything it needs.

Setup for Local Development (Windows)

WeasyPrint needs the same native libraries on Windows. You install them via MSYS2.

Step 1: Install MSYS2

  1. Download from https://www.msys2.org/
  2. Run the installer, keep all default options
  3. It installs to C:\msys64

Step 2: Install GTK Libraries

Open MSYS2 UCRT64 terminal (search "MSYS2 UCRT64" in Start menu — must be the UCRT64 one) and run:

pacman -S mingw-w64-ucrt-x86_64-gtk3

This installs GTK3 with ALL dependencies (pango, cairo, gdk-pixbuf, gobject, etc.). Close the MSYS2 terminal when done.

Step 3: Add to Windows PATH

  1. Windows Search → "Edit the system environment variables"
  2. Click Environment Variables
  3. Under System variables, find Path, click Edit
  4. Click New → type: C:\msys64\ucrt64\bin
  5. Click OK on all dialogs

Step 4: Add DLL Directory in Python

Since Python 3.8+, Windows PATH alone is NOT enough for loading native DLLs. You must explicitly register the directory in your Python code. Add this near the top of app.py (before any weasyprint import):

import sys
import os

if sys.platform == 'win32':
    msys2_bin = os.path.join('C:', os.sep, 'msys64', 'ucrt64', 'bin')
    if os.path.isdir(msys2_bin):
        os.add_dll_directory(msys2_bin)

Note: This only runs on Windows — Docker/Linux ignores it completely.

Step 5: Install the Python Package

pip install weasyprint

Step 6: Restart VS Code

Restart VS Code completely (close and reopen — not just the terminal) so it picks up the new PATH entry.

Usage in Code

Here's how to use WeasyPrint in a Flask route to generate and return a PDF:

# Lazy import inside the route (avoids slowing down app startup)
import weasyprint

# Render HTML template to string
html_string = render_template('my_pdf_template.html', title='Hello', amount='5,000')

# Convert to PDF bytes
pdf_bytes = weasyprint.HTML(string=html_string).write_pdf()

# Return as downloadable file
return Response(pdf_bytes, mimetype='application/pdf',
                headers={'Content-Disposition': 'attachment; filename="file.pdf"'})

Template Tips

WeasyPrint has some key differences from rendering HTML in a browser:

  • No JavaScript — WeasyPrint renders HTML/CSS only
  • Page size control — Use @page { size: A4; margin: 0; } to control page dimensions
  • No external images — URLs won't load; embed images as base64 data URIs
  • No Google Fonts — Use system fonts (Arial, Helvetica, sans-serif)
  • Use mm units — For precise print layouts (e.g., padding: 10mm;)

Troubleshooting

Problem Cause Fix
cannot load library libgobject Missing system libs or DLL directory not registered Install MSYS2 + GTK3, add os.add_dll_directory()
Package libgdk-pixbuf2.0-0 has no installation candidate Debian Trixie renamed the package Use libgdk-pixbuf-2.0-0 (with hyphens)
Images missing in PDF WeasyPrint can't fetch from localhost Embed images as base64 data URIs
Fonts look different Google Fonts not available Use system fonts in CSS

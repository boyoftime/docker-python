Part 1: Installation with Docker

We use the highly optimized linuxserver/kasm image. We assign Host Port 8095 to avoid conflicts with your other services.

Step 1: Create the Project Directory

mkdir -p /root/docker-deployment/kasm
cd /root/docker-deployment/kasm

Step 2: Create the `docker-compose.yml` File

nano docker-compose.yml

Paste the following configuration:

services:
  kasm:
    image: lscr.io/linuxserver/kasm:latest
    container_name: kasm
    # CRITICAL: Required for Kasm to spawn Docker containers inside itself
    privileged: true 
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Etc/UTC
    volumes:
      - ./data:/opt
      - ./profiles:/profiles
    ports:
      # Maps your host port 8095 to Kasm's internal secure port (3000)
      - "8095:3000" 
    networks:
      - nginx-proxy
    restart: unless-stopped

networks:
  nginx-proxy:
    external: true

Step 3: Launch the Container

docker compose up -d

Part 2: Initial Setup & Security

1. Run the Wizard

Open https://YOUR_SERVER_IP:8095 (Accept the security warning). Follow the wizard to create your admin account.

2. Secure with Nginx Proxy Manager

To use Kasm properly, we must route it through a secure domain name so WebSockets (the video stream) can function securely.

  • Domain Names: kasm.yourdomain.com
  • Scheme: https (Crucial: Kasm uses HTTPS internally)
  • Forward Hostname / IP: kasm
  • Forward Port: 3000
  • Websockets Support: ENABLED (Required for video stream)

Part 3: The Crucial "Zone" Fix

Because Kasm is sitting behind Nginx Proxy Manager, you MUST configure the Zones or the desktop will not load.

Common Error: If your screen gets stuck at 100% Loading, it is because of this setting.

  1. Go to https://kasm.yourdomain.com and log in.
  2. In the left menu, click Infrastructure -> Zones.
  3. Click the Edit (pencil icon) next to the default zone.
  4. Scroll down and configure the settings exactly like this:
    • Allow Origin Domain: kasm.yourdomain.com
    • Upstream Auth Address: proxy
    • Proxy Hostname: kasm.yourdomain.com
    • Proxy Port: 443
  5. Click Save at the bottom.

Part 4: Enabling Root Access (Kali/Ubuntu)

By default, Kasm sessions run as a standard user (`kasm-user`). To run commands like `apt install` inside a terminal, you need to enable Root permissions for that specific image.

  1. Go to Admin -> Workspaces.
  2. Find the image you want (e.g., Kali Linux) and click Edit (Pencil Icon).
  3. Scroll down to the Docker Run Config section.
  4. Find the field labeled Docker Run Config Override (JSON).
  5. Paste exactly this code into that box:
{"user":"root"}
  1. Click Save.
  2. Launch a NEW session (You must destroy any old running sessions for this to take effect).
  3. Open the terminal in Kali and type whoami. It should say root.

Note: You can now run `apt update` and `apt install` without using `sudo` or a password.

Part 5: Preventing Crashes (Swap File)

Kasm workspaces are heavy. If you run out of RAM (e.g., compiling large files), the workspace will crash with a Killed error. To prevent this, we add a "Swap File" to your VPS, which acts as emergency RAM.

1. Create a 4GB Swap File

Run these commands on your VPS terminal (SSH):

# Create and enable a 4GB swap file
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# Make it permanent (starts on reboot)
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

You can verify it works by typing free -h.

2. How to Remove Swap (Return to Normal)

If you later decide you want that disk space back:

# Turn off swap
sudo swapoff /swapfile

# Remove the file
sudo rm /swapfile

# Remove the line from fstab to stop it from loading on boot
sudo nano /etc/fstab
# (Delete the line that says '/swapfile none swap...')

Part 6: Decommissioning Kasm

If you want to completely remove Kasm Workspaces from your server:

  1. Remove Proxy Host: Delete the entry in Nginx Proxy Manager.
  2. Stop Containers: 
    cd /root/docker-deployment/kasm
docker compose down -v
  3. Delete Files: 
    cd ..
rm -rf kasm
  4. Clean Docker Images (Optional): Kasm downloads many large images (Chrome, Kali, etc). To free up space, run: 
    docker system prune -a
    (Warning: This deletes ALL unused Docker images on your system, not just Kasm).
